## Settings

| Setting | Value | Why |
| --- | --- | --- |
| Visibility | **Public** | Play has to be able to fetch it. Unlisted usually works, but private is rejected outright and public is the safe choice. |
| Category | **Gaming** | |
| Video language | **Turkish** | |
| Made for kids | **No, it's not made for kids** | The game is general-audience, not directed at children. Marking it as made for kids strips comments and other features for no benefit. |
| Age restriction | **No** | Play rejects age-restricted videos. |
| Monetization / ads | **Off** | Ads rolling over a store promo look bad and Play discourages them. |
| License | **Standard YouTube License** | |
| Comments | Default (allow, hold potentially inappropriate) | |
| Thumbnail | `youtube-thumbnail-1280x720.png` | Custom thumbnails need a verified channel; if the channel is not verified yet, verify it by phone first, otherwise YouTube picks a frame on its own. |
| Playlist | "Çengel Bulmaca" | Keeps later clips (update videos, gameplay) together. |
| Shorts | No | 16:9 and 18 s — it belongs in the normal feed. |
| End screen / cards | Optional | A link card to Play needs the channel to be linked to the associated website first. |

## After the upload

1. Copy the watch URL — the `https://www.youtube.com/watch?v=…` form.
   Do **not** use a `youtu.be` short link, a Shorts URL or a playlist URL;
   Play's field validates the watch form.
2. Play Console → the app → **Grow → Store presence → Main store listing** →
   **Promo video** → paste → Save → send the listing for review.
3. The video shows up on the listing above the screenshots, so keep the first
   two seconds readable: the title card is there for exactly that.
