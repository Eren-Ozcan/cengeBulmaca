# Release notes

The "What's new" text pasted into Play Console for each release. Mind the
character limit: 500 characters per language.

> **Note:** like the store listing, the note itself is kept in Turkish — it is
> pasted as-is into the Turkish Play Store listing. Only the surrounding
> documentation is in English.

## 1.3.0 (versionCode 6)

```
Bu sürümde:

• 200 bulmaca! Bulmaca havuzu büyüdü ve hepsi tek bir ızgara boyutunda: daha
ferah 8x10.

• Zorluk sıralaması yenilendi — baştaki bulmacalar daha kolay, sona doğru
gerçekten zorlaşıyor.

• Soru metinleri elden geçirildi; cevabı ele veren ipuçları değiştirildi.

• Küçük ekranlarda ızgaradaki soru yazılarının kenardan kesilmesi giderildi.

İyi bulmacalar!
```
