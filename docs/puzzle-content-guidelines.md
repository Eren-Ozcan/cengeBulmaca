# Puzzle content guidelines

Rules distilled from the 2026-08-15 full-content audit (`puzzle-audit-2026-08-15.md`).
Apply these when writing new puzzles (301+) or editing existing clue text.

## Factual correctness

- **PA** ("ayak" sözcüğü) is Farsça-kökenli, not Fransızca.
- **TAVŞAN** is not a kemirgen (rodent) — it's tavşangiller (lagomorph). Don't call it kemirgen.
- **KAZA** is subordinate to **İL** (kaza/ilçe is the sub-unit) — never phrase it as if the
  il belongs to the kaza.
- **Tİ** (hece) is a borazan/zurna (wind instrument) sound, not a trampet (percussion) sound.
- **HALA** is the father's sister; **TEYZE** is the mother's sister. Don't swap them.
- **TERAZİ** (burç) starts in late September, not October — October's sign is Akrep.
- **ER** is by definition rütbesiz (no rank) — never clue it as "rütbeli".
- **KAZ** says "gak gak", not "vak vak" — "vak vak" is ÖRDEK's sound.
- **İKİZ** vs **İKİZLER**: the zodiac sign's Turkish name is "İkizler", not "İkiz" — either
  reclue around the twin-sibling meaning or use the full sign name as the answer.
- **AB** ("su" anlamında) is Farsça/Divan edebiyatı usage, not Eski Türkçe.
- **ATİNA**: clue it as "Yunanistan'ın başkenti", not "Ege'deki antik Yunan başkenti" —
  ancient Greece had no single capital, and Athens isn't "in the Aegean".
- **BİR** is not "en küçük doğal sayı" — 0 is, in the Turkish curriculum. Use "en küçük
  sayma sayısı" instead if BİR is the intended answer.
- **TAVA**: the clue word is "saplı" (handled), not "sapı" — recurring typo, check for it.

## Avoid ambiguity — one clue, one defensible answer

Never write a clue that fits multiple equal-length real answers players can't distinguish
between. This came up mainly with:
- Musical notes (DO/RE/Mİ/FA/LA/Sİ) — never clue a note as just "Bir nota". Say what it's
  relative to: "Do'dan sonraki nota", "Mi ile Sol arasındaki nota", etc.
- Capital-city clues that name a region but not the country ("Orta Asya'daki bir başkent",
  "Balkanlar'daki bir başkent") — always name the specific country.
- Generic zodiac/conjunction/neighboring-country clues ("Bir burç", "Bir bağlaç", "Komşu bir
  ülke") — same problem, same fix: be specific enough that only one answer fits.

## Clue variety — don't overuse generic phrasing, even when it's not technically wrong

Per user direction (2026-08-15): even when a clue/answer pair is internally *consistent*
across many puzzles (same text, same answer every time — not a bug by the letter-conflict
definition), overly generic one-size-fits-all phrasing for simple/common answers should
still be avoided where practical. Example: plain "Bir nota" reused verbatim across 30+
puzzles for six different notes was flagged as a real problem to fix (not just the letter
conflict) — the underlying complaint was the generic phrasing itself, not only the cases
where it collided with a different answer. When writing or revising clues for short/common
fill words, prefer a phrasing distinct enough to feel like an actual clue rather than a
category label, even if reusing the *same* answer elsewhere in the set is unavoidable.
